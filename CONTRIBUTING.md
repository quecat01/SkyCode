# Contributing to Sky Code

Thank you for your interest in contributing to Sky Code.

## How to contribute

1. Fork the repository
2. Create a branch for your change (`git checkout -b my-feature`)
3. Make your changes
4. Run the test suite and confirm all tests pass (`npm test`)
5. Run the build and confirm it is clean (`npm run build`)
6. Commit your changes with a clear message describing what changed and why
7. Open a pull request against the `main` branch

## Code standards

- All code must be written in TypeScript
- All new features must include tests
- The full test suite must pass before a pull request will be merged
- The TypeScript build must complete without errors

## AI-assisted contributions

Sky Code was developed with AI coding assistance. Contributions that include
AI-generated code are welcome, subject to these conditions:

- You must review all AI-generated code before submitting it
- You must be satisfied the code is correct, secure, and does not reproduce
  protected third-party code
- By submitting a pull request you confirm that your contribution does not
  incorporate code that infringes third-party rights
- Disclose in your pull request description if significant portions were
  AI-generated

## Security issues

Please do not open public GitHub issues for security vulnerabilities.
See [SECURITY.md](SECURITY.md) for the private reporting process.
